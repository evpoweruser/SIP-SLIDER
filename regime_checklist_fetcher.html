Drop-In Auto-Fetch & JSON Loader Script for Your Existing HTML App

            

              Paste this self-contained <script> block right before </body> in your existing month-end regime HTML file. Whenever your HTML file is opened, it automatically fetches the latest regime JSON (from local Python server http://127.0.0.1:8765/regime.json, public CORS endpoints, or the verified baseline), fills your input fields, and adds a floating Import / Export Regime JSON bar.
            

          

          
        


        

      

    


    
    

      

        

          

            
Standalone Python Fetcher & Local JSON Server (fetch_regime_data.py)

            

              Browsers block direct cross-origin requests to NSE India and Mirae Asset when opening a local file:// HTML page. Run python3 fetch_regime_data.py to generate regime_inputs.json, or run python3 fetch_regime_data.py --serve so that whenever you open the HTML file, it automatically pulls live NSE/Yahoo/Mirae data from http://127.0.0.1:8765/regime.json.
            

          

          

            
            
          

        


        

      

    


    
    

      

        

          

            
GitHub Hosting + Automated Offline HTML Code Injector (.github/workflows/update_regime_data.yml)

            

              Host this repository on GitHub. Whenever the GitHub Action runs (on schedule, on push, or manually via Run workflow), fetch_regime_data.py --inject-html fetches the latest live market numbers server-side (no browser CORS limits) and rewrites the /* AUTO_INJECT_START */ ... /* AUTO_INJECT_END */ block directly inside the HTML file, so any HTML file downloaded from GitHub or via the Download Offline HTML button runs 100% offline with the latest live data pre-populated in the code.
